# Tang

A "from the ground up" operating system made in Python.
Tang uses virtual RAM as a python list, and storage as a custom binary file using the ".mem" extension.
Tang is build off of a custom language called Citrus. The Disk Manager uses a custom format called "Tart" to initialize and format the disks. Tart uses satements like a language like C/Java would to create the disks.

Make sure to modify "runTangPY.bat" to work with your specific location for the Repo. Yes, I am the owner of the death star.
