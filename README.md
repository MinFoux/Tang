# Tang

A toy operating system made in Python. The next step up from my previous project called LineOS.
Tang uses a python byteArray as virtual RAM, and storage as a custom binary file using the ".mem" extension.
Tang is build off of a custom language called Citrus. The Disk Manager uses a custom format called "Tart" to initialize and format the disks. Tart uses satements like a language like C++/Java would to create the disks.
