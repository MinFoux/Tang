# Tang v00 Changelog
_"How much barbeque sauce can one dude make??"_

1 - Made initial programs
2 - Formed intial RAM system, named PTIMB
3 - Allowed PTIMB to be constructed of any size of Byte. The length of PTIMB is the size of the integer limit of the byte size.
4 - Changed from PTIMB being a list of strings to being a bytearray.
5 - The Tang disk is now a binary file.
6 - Made TACOIN, which is the octet rendering system for Tang.
7 - PurgeArray now works. And you betcha it purges arrays. Oh yeah it purges arrays.
8 - Pressing ctrl+c or alt+f4 now exits the TACOIN window. This is the alternative to needing to open task manager in order to kill TACOIN. (Fun fact! TACOIN is pronounced Tack-yo-een, because it is a refrence to Kakyoin from JoJo's bizarre Adventure!)
9 - Cleaned up the TACOIN code. You now need to call tacoin.start to open the terminal, instead of the terminal opening the moment you import TACOIN as a module.
