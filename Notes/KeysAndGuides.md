# Keys and Guides.md

Asset array:
	1 = Code Address
	2 = Stack Address
	3 = Process pointer
	4 = Read state
	
Read state key:
	1 = Read a new component
	2 = Read a new argument and stash
	3 = Wait until ENDIF
	
Component Keys:
	1 = Push
	2 = Print current interpreter
	100 = IF
	101 = ENDIF
	200 = End program
